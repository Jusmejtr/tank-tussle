# Tank Tussle — play in the browser

A fan remake in the spirit of the 2015 Tank Trouble: random mazes, slow bouncing bullets, one hit and you're out, weapon crates, bots.

**Same keyboard (no server needed):** pick 0–4 players + up to 8 tanks with bots, press Play.
P1 Red E/S/D/F + Q · P2 Green arrows + M · P3 Blue I/J/K/L + U · P4 Yellow Numpad 8/4/5/6 + Numpad 0. On a phone: on-screen stick + FIRE.

**Online (each player on their own device):** enter your name → *Create room* → send friends the link (or the 4-letter code) → host adds bots if wanted → *Start game*.
Online controls: arrows (or WASD) + Space/M. Needs the game server configured in `config.js`.

Weapons from crates: Gatling, Laser (aim guide), Frag bomb (fire again to burst), Death ray (charge), Homing missile, Mines — the tank's turret changes to show what it carries.
